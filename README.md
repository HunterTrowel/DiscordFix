> ### РЕАКЦИЯ АНТИВИРУСОВ
> Антивирус может среагировать на WinDivert.  
> Для работы zapret нужен WinDivert — инструмент перехвата и фильтрации сетевого трафика.
> Один и тот же инструмент могут применять как безопасные, так и вредоносные программы, но сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит файлы WinDivert к инструментам повышенного риска или хакерским средствам. В результате файл удаляется и отправляется в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, лучше добавить исключение; при недостаточном понимании настроек рекомендуется отключить обнаружение PUA.

## ⚙️Установка и использование

1. Активируйте Безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется
    * На роутерах Keenetic активируйте параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут завершиться проблемами

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/HunterTrowel/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно пропустить

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите необходимый файл
    * Чтобы определить рабочую стратегию, откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, выберите в **`service.bat`** -> `Install Service` -> *подходящую стратегию*

## ℹ️Назначение файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск подходит для проверки разных стратегий. Результат зависит от множества условий, поэтому **перебирайте варианты (ALT, FAKE и другие), пока не найдёте подходящий для себя**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — убрать стратегию и WinDivert из служб
  - **`Check Status`** — показать состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние отображается в скобках (включено/выключено).
  - **`IPSet Filter`** — настроить режим обхода для сервисов из `ipset-all.txt`.  
  Параметр полезен при проверке ресурса, который без zapret открывается, а с ним работает неправильно.  
  Возможные статусы:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP сопоставляется со списком
    - `any` — фильтруется любой IP  
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить текущий фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — проверить распространённые причины неработоспособности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не видно

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться `winws.exe`, отвечающий за обход. Его можно найти на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/HunterTrowel/zapret-discord-youtube/issues/522)

### Не удаётся подобрать стратегию
- Откройте командную строку с правами администратора
- Выполните по очереди следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Скопируйте содержимое открывшегося блокнота целиком
  - С помощью текстового редактора, запущенного от имени администратора, откройте файл `hosts` в созданной папке
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте соединение ещё раз. Если результат не изменился, убедитесь, что файл действительно сохранён.

#### Работа не гарантируется. Если этот способ не сработал, используйте [настольную версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/HunterTrowel/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Даже подходящая сейчас стратегия может перестать работать после её обнаружения.
> В этом репозитории собран ряд различных стратегий. Если ни одна не дала результата, создайте новую на основе одной из существующих, изменив её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`

- Убедитесь, что нужный адрес присутствует в списке доменов или IP-адресов

- Переключитесь на другие стратегии, например **`ALT`** или **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- См. [#765](https://github.com/HunterTrowel/zapret-discord-youtube/issues/765)

### Полная переустановка или обновление
- Сохраните добавленные вами ресурсы и прочие данные
- Перезапустите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце подтвердите `Y`
- Удалите каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/HunterTrowel/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива через контекстное меню. Если внизу справа есть флажок разблокировки, установите его, нажмите "Применить" и затем "ОК"
- Распакуйте архив в новый каталог в корне диска, избегая пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если соединения нет, закройте программу через значок замка на панели задач и попробуйте следующую стратегию
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Определите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если раньше доступ работал.
- Дополнительная информация — в [#251](https://github.com/HunterTrowel/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Удостоверьтесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- В `service.bat` перейдите в `Run Diagnostics` и очистите кэш Discord
- Проверьте работу приложения Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если браузерная версия тоже недоступна, снова проверьте все стратегии: YouTube и Discord могут требовать разные варианты
- См. также [#252](https://github.com/HunterTrowel/zapret-discord-youtube/discussions/252)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/HunterTrowel/tg-ws-proxy)
- Либо выберите бесплатный MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Начните с универсального варианта:
- обновите ipset через `service.bat` и включите `Game Filter`
- если результата нет, дополнительно активируйте `ipset any`

Учтите, что `ipset any` может нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно: выясните IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`

Если это не помогло, создайте обсуждение в разделе [Discussions](https://github.com/HunterTrowel/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Проблемы нет в списке

- Сообщите о ней [здесь](https://github.com/HunterTrowel/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Расширить список обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен из неё фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые следует исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
